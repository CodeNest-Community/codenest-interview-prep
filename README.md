# 🚀 CodeNest Interview Prep — Open Source Platform

An open-source interview preparation portal built for the Uzbekistan developer community.

## 🌟 Project Goal

To collect interview questions and answers on HTML, CSS, JavaScript, Git, and Linux in one place for junior and beginner developers, and to share knowledge in the spirit of open source.

## 🛠 Technologies

- HTML5
- CSS3 (Vanilla / Custom Variables)
- JavaScript (ES6+)

## 🤝 How to Contribute

1. **Fork** the repository.
2. Add a new question and answer to the `js/questions.js` file.
3. Submit a new **Pull Request (PR)**!

Developed with ❤️ by **CodeNest Community**.
