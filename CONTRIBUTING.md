## 🛠️ Qanday qilib hissa qöşiş mumkin?

Loyihaga hissa qöşişning 3 ta asosiy yöli bor:

1. **Yangi Intervyu Savoli Qöşiş:** HTML, CSS, JS, TS, React, Node.js yoki Python bo'yicha amaliy savol va javoblar.
2. **Xatoliklarni Tuzatiş (Bug Fix):** Kod grammatikasi, dizayn yoki logikadagi kamchiliklarni to'g'rilaş.
3. **Dizayn va UIni Yaxşilaş:** CSS/Tailwind orqali interfeysni yanada qulay qilish.

# 🚀 CodeNest Interview Prep — Contributing Guide

Welcome to the CodeNest open-source community! This project is an open-source platform designed to help developers prepare for technical interview questions.

You, too, can contribute to the development of this project!

---

## 🛠️ How to Contribute?

There are 3 main ways to contribute to the project:

1. **Add a New Interview Question:** Practical questions and answers covering HTML, CSS, JS, TS, React, Node.js, or Python.
2. **Fix Bugs:** Correct issues related to code syntax, design, or logic.
3. **Improve Design and UI:** Enhance the user interface using CSS/Tailwind to make it more user-friendly.

---

## 📌 Steps to Submit Your First Pull Request (PR)

### Step 1: Fork the Repository

Click the **Fork** button in the top-right corner of the project page to create a copy in your own GitHub profile.

### Step 2: Clone the Repository

```bash
git clone https://github.com/CodeNest-Community/codenest-interview-prep.git
cd codenest-interview-prep
```
